** Simple Policy Experiments: Changing Prices

If price of a good increases/decreases, what's the cost to the
household?  Ask a related question: If a price $p_1$ increases, how
much /income/ do we need to give to the household to make it just as
well off as it was at the old prices?

Summarize this as the  /compensating variation/ associated with the
price change.

[[./compensating_variation.png]]

Compensating Variation can also be measured as the (change in the)
area under the *Hicksian* (or *compensated*) demand curve:

[[./compensating_variation_newexpenditure.png]].

*** Marshallian vs. Hicksian Demand Curves

Let's look at Marshallian & Hicksian demands---one way of thinking
about the Hicksian (compensated) curves is that they  eliminate the
income effect associated with changing prices.

*** Welfare measures
#+begin_src jupyter-python :results silent
def compensating_variation(U0,p0,p1):
    x0 = uga.expenditure(U0,p0)
    x1 = uga.expenditure(U0,p1)

    return x1-x0

def revenue(U0,p0,p1,type='Marshallian'):
    """(Un)Compensated revenue from taxes changing vector of prices from p0 to p1.

    Note that this is only for *demand* side (i.e., if supply perfectly elastic).
    """
    
    dp = p1 - p0 # Change in prices

    c = uga.demands(U0,p1,type=type)

    dp,c = dp.align(c,join='inner')

    return dp.T@c


def deadweight_loss(U0,p0,p1):
    """
    Deadweight loss of tax/subsidy scheme creating wedge in prices from p0 to p1.

    Note that this is only for *demand* side (i.e., if supply perfectly elastic).
    """
    cv = compensating_variation(U0,p0,p1)

    return cv - revenue(U0,p0,p1,type='Hicksian') 
    

 #+end_src

** Compensated Nutritional Adequacy

The welfare measures above tell us about money or /budget/---how much a price
change costs the household.  But we care about /nutrition/.  Using
Hicksian (compensated) demands, we can ask: if we hold the household's
utility fixed, how does changing a single price affect nutritional
adequacy?

*** Compensated nutrient demands

 #+begin_src jupyter-python :results silent
# Average household characteristics
dbar = uga.d[rdi.columns].mean()

# Minimum nutrient requirements for the average household (weekly)
hh_rdi = rdi.replace('',0)@dbar*7

UseNutrients = ['Protein','Energy','Iron','Calcium','Vitamin C']

def compensated_nutrient_demand(U,p):
    """Nutrient vector from Hicksian demands at utility U and prices p."""
    c = uga.demands(U,p,type='Hicksian')
    fct0,c0 = fct.align(c,axis=0,join='inner')
    return fct0.T@c0

def compensated_nutrient_adequacy_ratio(U,p):
    """NAR using Hicksian demands: holds utility fixed as prices vary."""
    return compensated_nutrient_demand(U,p)/hh_rdi
 #+end_src

*** Compensated NAR vs. price

How does nutritional adequacy respond to a price change, once we
compensate the household so utility is unchanged?

 #+begin_src jupyter-python
fig, ax2 = plt.subplots()
ax2.plot(P,[np.log(compensated_nutrient_adequacy_ratio(U0,ceteris_paribus_price(my_j,p0))[UseNutrients]) for p0 in P])

*** Costs of improving nutrition

raise the NAR for a particular nutrient above 1), what is the
